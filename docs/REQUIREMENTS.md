# Macorn 要件定義書 v1.0（確定版）

> 旧名 noxy。2026-10-26 にアプリ名を Macorn に変更した（D7）。本文中の例に出てくる noxy は旧名のまま残している。

最終更新: 2026-10-26

macOS 標準の Finder をベースに、開発者が使いやすいように作り変えた「ファイルマネージャーアプリ」の要件をまとめる。

## 4. 軸の機能① 2画面表示

ウィンドウを左右に分け、片方からもう片方へファイルをコピー・移動する機能。

### 4.1 基本動作

| ID | 要件 | 優先度 |
|---|---|---|
| P-01 | ⌘\ で2画面表示の ON / OFF を切り替える。ON にすると、右側には左側と同じフォルダが開く | ◎ |
| P-02 | 分割状態はタブごとに持つ（タブ A は2画面、タブ B は1画面、ができる） | ◎ |
| P-03 | 操作対象の画面（アクティブ画面）を、枠線の色とパンくずの濃さではっきり区別する | ◎ |
| P-04 | Tab キー、またはクリックでアクティブ画面を切り替える | ◎ |
| P-05 | 左右の画面はそれぞれ独立した「戻る / 進む」履歴・選択状態・スクロール位置を持つ | ◎ |
| P-06 | 境界線をドラッグして幅を変えられる。ダブルクリックで 50:50 に戻す | ◎ |
| P-07 | 2画面を OFF にしたときは、アクティブだった側の画面が残る | ◎ |
| P-08 | ウィンドウ幅が狭いとき（目安 700px 未満）は、2画面を一時的に1画面表示にする | ○ |

### 4.2 画面間の操作

| ID | 要件 | ショートカット | 優先度 |
|---|---|---|---|
| P-10 | 選択中のファイルを反対側のフォルダへ**コピー** | F5 | ◎ |
| P-11 | 選択中のファイルを反対側のフォルダへ**移動** | F6 | ◎ |
| P-12 | 反対側の画面を、こちらと同じフォルダにする | ⌘⌥= | ◎ |
| P-13 | 左右のフォルダを入れ替える | ⌘⌥U | ○ |
| P-14 | 選択中のフォルダを反対側の画面で開く | ⌘⌥→ / ⌘⌥← | ◎ |
| P-15 | 左右のフォルダを比較し、片方にしかないファイル・内容が違うファイルを色で示す | — | △ |

- **F5 / F6 の確認ダイアログ**: 「◯件を ~/path/to/dest へコピーします」とコピー先を表示し、Enter で実行、Esc で中止する。設定で確認なしにもできる。
- **ファンクションキーについて**: Mac のキーボードは F キーが音量などの操作に割り当てられているため、fn を押しながらでないと F5 / F6 が届かないことがある。そのため、同じ操作をコマンドパレットからも実行できるようにし、ショートカットは設定で変えられるようにする（K-01）。
- 画面間のドラッグ＆ドロップは Finder と同じ動き（同じボリューム内なら移動、別ボリュームならコピー、⌥ を押すと必ずコピー）。

## 5. 軸の機能② コマンドパレット

⌘K で検索窓を開き、操作・フォルダ・ファイルを名前の一部で探して実行する機能。

> 補足: Finder では ⌘K は「サーバへ接続」だが、Macorn ではコマンドパレットに使う。「サーバへ接続」はパレットから実行する。

### 5.1 基本動作

| ID | 要件 | 優先度 |
|---|---|---|
| C-01 | ⌘K でウィンドウ上部中央にパレットを開く。Esc で閉じる | ◎ |
| C-02 | あいまい検索（例: `nwf` で「New Folder」がヒット）。日本語のメニュー名とローマ字の両方でヒットする | ◎ |
| C-03 | ↑↓ で選択、Enter で実行 | ◎ |
| C-04 | 入力してから結果が出るまで 50ms 以内 | ◎ |
| C-05 | よく使う項目・最近使った項目ほど上に出す | ◎ |
| C-06 | 何も入力していないときは、最近使ったコマンドと最近開いたフォルダを表示する | ◎ |

### 5.2 検索対象と入力の頭文字

| 入力の頭文字 | 対象 | 例 | 優先度 |
|---|---|---|---|
| なし | すべて（下の全種類をまとめて表示） | `repo` | ◎ |
| `>` | コマンドだけ（メニューにある全操作。右側にショートカットも表示） | `>hidden` | ◎ |
| `/` または `~` | パス入力。Tab で補完し、Enter でそのフォルダへ移動 | `~/repo/no` | ◎ |
| `@` | 表示中フォルダ内のファイル（サブフォルダも含めて名前で探す） | `@readme` | ○ |
| `#` | サイドバー・ブックマーク | `#work` | ○ |

### 5.3 フォルダジャンプ（履歴からの移動）

| ID | 要件 | 優先度 |
|---|---|---|
| C-10 | 開いたフォルダを履歴として記録し、「よく開く・最近開いた」順に点数をつける（zoxide と同じ考え方） | ◎ |
| C-11 | フォルダ名の一部を入力するだけで、深い場所のフォルダへ移動できる（例: `noxy` → `~/repo/hobby/noxy`） | ◎ |
| C-12 | 消えたフォルダは履歴から自動で外す。履歴は設定画面から消せる | ○ |

### 5.4 実行方法の切り替え

| キー | 動作 | 優先度 |
|---|---|---|
| Enter | アクティブ画面で開く / コマンドを実行 | ◎ |
| ⌘Enter | 反対側の画面で開く（1画面のときは2画面にしてから開く） | ◎ |
| ⌥Enter | 新しいタブで開く | ◎ |
| ⌘⇧Enter | ターミナルで開く | ○ |

## 9. 非機能要件

### 9.1 性能

| 項目 | 目標値 |
|---|---|
| 起動 | 1秒以内にウィンドウ表示 |
| フォルダ表示 | 1万ファイルのフォルダを 0.5 秒以内に表示開始。スクロールがカクつかない |
| キー操作の反応 | 100ms 以内（コマンドパレットの検索は 50ms 以内） |
| 重い処理 | サイズ計算・コピー・Git 状態の取得はすべて裏で実行し、画面を止めない |
| 外部の変更 | 他アプリやターミナルでの変更を 1 秒以内に表示へ反映 |

### 9.2 安全性

- 削除は原則ゴミ箱経由。完全削除は確認必須
- コピー・移動が途中で失敗しても、元ファイルは失われない（移動は「コピー完了を確認してから元を消す」順で行う）
- 権限がないフォルダを開いても落ちず、「アクセス権がありません」と表示して設定方法を案内する

### 9.4 配布

- Mac App Store は使わず、**Developer ID 署名＋公証で直接配布**する
  - 理由: App Store のアプリは「サンドボックス」という制限の中で動き、ユーザーが許可したフォルダ以外を自由に読めない。また、ターミナルやエディタを操作する機能も制限される。ファイルマネージャーとしては致命的なため
- 自分用の段階では、署名だけして手元でビルド・実行する
- 配布用の DMG（Developer ID 署名・公証つき）は `scripts/release.sh` で作る（2026-10-27）
- DMG は LP（https://macorn.vercel.app）から配る。リポジトリが非公開で GitHub Releases は外から落とせないため、LP と同じ Vercel に置く（2026-10-27 のユーザーの判断「申請は不要。LP から公開する方針で」）
- DMG は開くとドラッグを促す背景と配置で表示する。「アプリケーション」フォルダの外（DMG の中・ダウンロードなど）から起動したら、移動するかを尋ね、移すと開き直して DMG を取り出す（2026-10-27 のユーザーの依頼）
- 新しい版は、起動時（設定でオフにできる）とメニューの「アップデートを確認…」で LP の `version.json` を読んで知らせる。外部ライブラリを使わないため Sparkle は使わない（2026-10-27 のユーザーの判断）
- 「今すぐ更新」で、DMG のダウンロード・署名の確認（Developer ID・同じチーム・同じアプリ・知らされた版）・入れ替え・開き直しまで自動で行う。確かめられない・書き込めないときはブラウザでのダウンロードに戻す（2026-10-31 のユーザーの依頼。それまでは DMG から手動で入れ替えていた）
- 初回起動時に「フルディスクアクセス」と「他のアプリの操作（ターミナル連携用）」の許可を案内する

## 10. 技術方針

| 項目 | 方針 | 補足 |
|---|---|---|
| 言語 | Swift 6 | |
| UI | SwiftUI ＋ AppKit | ウィンドウ・設定画面・パレットは SwiftUI。大量のファイルを並べるリスト部分は、動作の軽い AppKit の NSOutlineView を使う |
| ファイル操作 | FileManager / NSWorkspace | ゴミ箱移動は `NSWorkspace.recycle` を使い、Finder の「戻す」にも対応させる |
| 外部の変更検知 | FSEvents | |
| プレビュー・サムネイル | Quick Look（QLPreviewPanel / QLThumbnailGenerator） | |
| あいまい検索 | 自前実装（fzf と同じ方式の点数づけ） | ローマ字対応のため、メニュー名の読みを事前に持たせる |
| ターミナル連携 | Terminal・iTerm2 は AppleScript、他は `open -a` やコマンドライン引数で起動 | アプリごとに起動方法を切り替える仕組みにして、後から追加しやすくする |
| Git 状態 | `git status --porcelain` を裏で実行し、結果を一時保存 | 大きなリポジトリでは実行間隔を空ける |
| 設定・履歴の保存 | 設定は UserDefaults、フォルダ履歴は SQLite | |
| 内蔵ターミナル（v1.x） | SwiftTerm ライブラリを候補とする | |

### 要件から変えた点・補足

| 項目 | 内容 |
|---|---|
| ⌘F | Finder では検索だが、Macorn では「表示中フォルダの絞り込み」（S-04）に使う |
| ⌘K | Finder の「サーバへ接続」は、メニュー（移動 › サーバへ接続…）とパレットから開く |
| Return | メニューには割り当てず、一覧の中でだけ「名前を変更」になる（入力欄の Return と区別するため）。複数選択なら一括で名前を変更（F-13）を開く |
| Tab | 一覧の中でだけ「もう一方の画面へ」になる |
| T-03 新しいタブで開く | 対応できるのは iTerm2（AppleScript）と WezTerm（付属コマンド）。ターミナル・Ghostty・Warp は新しいウィンドウで開く |
| 置き換え（F-08） | 置き換えた元の項目は完全には消さず、ゴミ箱へ移す（取り消しで戻せる） |
| 保存先 | フォルダ履歴は `~/Library/Application Support/Macorn/history.sqlite`、設定は UserDefaults |
| S-07 タグ | macOS 標準のタグではなく、Macorn 独自のタグにした（2026-10-26 のユーザーの選択）。名前・色を自由に決められ、「仕事/案件A」のように階層にできる。Finder からは見えない。保存先は `~/Library/Application Support/Macorn/tags.json`。Finder などで移動・改名された項目もブックマークで追いかける |
| S-05 プレビュー | Markdown を外部ライブラリなしの自前の変換で HTML にし、WKWebView で表示する。HTML はファイルをそのまま表示し、読めるのは同じフォルダのファイルだけ。ファイルに書かれたスクリプトは初めは動かさず、HTML ではボタンでファイルごとに動かせる。画像は NSImageView、PDF は PDFKit、動画・音声は AVKit、それ以外の書類はクイックルックで表示する |
| テーマ | 外観とアクセントカラー（9色＋自由な色）を選べる。選択中の行・操作対象の画面の線・パレット・リンクの色に使う |
| N-05 お気に入り | サイドバーの「よく使う項目」を「お気に入り」にした（★ボタン・⌃⌘T・ドラッグ＆ドロップで登録、表示名の変更）。お気に入りは「お気に入り」というタグの1つで、ほかのタグへドラッグで移せる（2026-10-26 のユーザーの依頼） |
| N-04 セクション | セクションはサイドバー上の見た目だけのまとまりで、属性は付けない。「お気に入り」「タグ」「場所」は残し、自分で作るセクションを足せる。1つのタグを置けるのは1か所だけ。初めての起動で「マイセクション」を1つ用意する（2026-10-26 のユーザーの依頼・選択） |
| K-04 | コマンドラインツールは `/usr/local/bin` に書けなければ `~/.local/bin` に入れる（管理者のパスワードを求めないため） |
| Finder の代わりに使う | 設定の切り替えで、ほかのアプリの「Finder に表示」を Macorn で開ける（macOS 全体の設定 `NSFileViewer`）。届くのはふつうの「開く」要求で、ファイルは入っているフォルダで選び（同じフォルダのものは1つのタブにまとめる）、フォルダはその中を開く。フォルダの既定のアプリは macOS 26.7 が変更を受け付けない（Finder にしか戻せない）ため対応しない（2026-10-27 のユーザーの依頼） |
| ファイルを Macorn で開く | PDF・Markdown・HTML・画像・動画・音声（プレビューできる種類）を「このアプリケーションで開く」に出し、設定から種類ごとに既定のアプリにできる。オフで前のアプリに戻す。macOS 26 では変更のたびに macOS の確認が出る。開くとフォルダの中で選んでプレビューを出す（プレビューを切っていても出す）。既定を Macorn にした種類を Macorn の中で開いたら、外に出さずその場でプレビューする（2026-10-27 のユーザーの依頼。前提の変更：それまでファイルの種類は対象外） |
