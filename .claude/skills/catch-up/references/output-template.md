# 出力テンプレート

チャットに Markdown で返す。対象は Step 1 で決めた1案件だけ。他の案件には触れない。

```markdown
## {案件名}

**目的**：{1文}
**現在地**：{どのマイルストーンまで終わったか。待ちになっている事項}
**次の一手**：{直近の作業・候補。根拠つき}

### 確定している前提

- {前提} — 根拠：{要件定義書の章／CHANGELOG の日付}

### これまでの経緯（新しい順）

- **{YYYY-MM-DD}** {作業の要約} — きっかけ：{依頼・会話}。意図：{なぜそうしたか}

### 次にやること・候補

| 優先 | 内容 | 出典 |
| ---- | ---- | ---- |

### 未確定事項・確認したいこと

- {項目} — {なぜ未確定か}

### 注意

- {前提の食い違い、CHANGELOG に未記録の変更、コミットしていない変更、推測を含む点}

> 参照：`AGENTS.md`、`CHANGELOG.md`（{最古}〜{最新}）、`docs/REQUIREMENTS.md`（{読んだ章}）、`README.md`、`git log` / `git status`
```

## 書き方のルール

- 冒頭の3行（目的・現在地・次の一手）だけで状況が分かるようにする
- 経緯は変更内容の羅列にしない。「きっかけ」と「意図」を1行にまとめる
- 古い経緯は直近5件程度に絞り、それ以前は「ほか◯件」とまとめる
- 日付は `M/D（曜）` か `YYYY-MM-DD`。「昨日」「先週」などの相対表現は使わない
- 推測には「（推測）」を付ける
- 「注意」が無ければ節ごと省く
